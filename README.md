# Hitlines

Daglig musikutmaning inspirerad av tidslinjespel: placera 10 låtar i rätt kronologisk ordning.
Ett fel avslutar spelet (ett extraliv via simulerad reklam finns i mockupen).

Statisk sajt (HTML + Tailwind CDN + Lucide) – inget byggsteg behövs.

## Köra lokalt
Öppna `index.html` i webbläsaren.

## Publicera
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
